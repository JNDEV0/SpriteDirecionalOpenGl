# SpriteDirecionalOpenGl

![Gameplay Demo](Textures/gameplay2.gif?raw=true)

## Gameplay

Este é um exemplo de animação de sprite 2D usando OpenTK para gráficos (OpenGL) e StbImageSharp para carregar a folha de sprites. O personagem pode ser controlado usando as teclas A e D ou as setas direcionais para se mover em 2 direções, com a animação correspondente sendo exibida.

Este projeto implementa um efeito de parallax scrolling. As diferentes camadas do cenário movem-se em velocidades distintas em relação ao personagem, o que cria uma convincente ilusão de profundidade. O movimento do personagem foi restrito ao eixo horizontal (esquerda/direita) para destacar este efeito visual.
