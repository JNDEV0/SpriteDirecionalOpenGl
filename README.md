# tileset 15x15 movimento 8 direcoes e Sprite Direcional OpenGl

![Gameplay Demo](Textures/gameplay3.gif?raw=true)

## Gameplay

Este é um exemplo de animação de sprite 2D usando OpenTK para gráficos (OpenGL) e StbImageSharp para carregar a folha de sprites. O personagem pode ser controlado usando as teclas WASD ou as setas direcionais para se mover em 8 direções (cardinais e diagonais) em um mapa de tiles isométrico. O objetivo é encontrar uma chave escondida no mapa e usá-la para abrir um baú. Ao abrir o baú, o jogador vence e o jogo termina, exibindo uma mensagem de vitória. O jogo pode ser reiniciado a qualquer momento após o término pressionando a tecla 'R'. O movimento é sobre os tiles, e o personagem não pode andar sobre tiles de água, árvores ou fora dos limites do mapa definido, com a animação correspondente sendo exibida para a direção do movimento.
